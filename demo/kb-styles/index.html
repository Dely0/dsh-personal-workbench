知识库页面 · 4 款样式选型

同一个假数据集（1,000 条），同一块面板尺寸（左「列表」右「详情」，和现在插件的骨架一致）。 每款都做了 修前 / 修后 两个版本，默认展示修前（= 现在的下拉 + 无分页）， 点卡片里的「修后」就能看到改造后的样子 —— 这样款式的差别不会被功能差别掩盖。 假数据里混了「一周内更新」与「本月更新」的条目，方便看分组效果。

全部卡片一起切： 款式之间可以反复切，挑一个你顺眼的告诉我编号即可。

四款的差别，一句话各是什么

#款式视觉性格适合什么
1卡片瀑布（Bento / 画廊）每条一张圆角卡片，彩色左边框标类型，2 列网格；像 Notion Gallery、Anytype条目 50–300 条、以"翻看"为主；条目上千后信息密度偏低
2密集列表 + 时间分组单列行，左侧色条 + 类型点，按「今天 / 本周 / 本月 / 更早」分组，底部编号分页条目上千仍好扫；最接近"专业工具"的观感
3左导航树 + 双栏类型变成左侧分组树（带条数），中间是紧凑列表，最右才是详情；像 SiYuan / Obsidian分类多、想要固定分类入口；面板宽度够（≥1000px）时最好看
4杂志式首屏 + 列表顶部一排统计卡 + 一条「最近更新」大卡，下面才是列表；像 Outline 首页想让知识库"有首页感"、能一眼看到最近沉淀了什么
  • 四款都带：搜索框、类型入口（Tab 或左树）、底部编号分页（50/页）。款式 2 额外带时间分组，款式 4 额外带统计首屏。
  • 四款都没有动数据结构：用的还是现有的 title / kindCode / tags / fileLink / sourceTaskId / updatedAt。
  • 方向可混搭：比如"款式 2 的列表 + 款式 4 的统计首屏"、"款式 3 的左树 + 款式 1 的卡片"。
