设计决策（请重点看表里 ⚠ 的两条）

项方案类型
分类形态知识库与任务列表统一改为 Tab 页（下划线式，带条数徽标）。知识库 = 4 个知识类型 + 「全部」；任务列表 = 9 个任务类型 + 「全部」，超过 10 个自动收进「更多 ▾」。已定
Tab 状态保持Tab 选择写本地存储（键 dsh.personal-workbench.tab.<view>），刷新 / 重开面板后保持；切走再回来也保持。已定
搜索标题 + 正文全文匹配（大小写不敏感），命中处高亮；任务列表再加描述。输入框 200ms 防抖，1000 级数据实时不卡。已定
筛选与 Tab、搜索 可叠加：知识库按标签 + 关联任务 / 有无本地文件；任务列表按状态 + 优先级 +（类型已升为 Tab）。筛选项显示各自条数。已定
排序知识库：更新时间（默认↓）/ 创建时间 / 标题。任务列表：更新时间（默认↓）/ 截止时间 / 优先级 / 创建时间 / 标题。切方向按钮 ↑↓。已定
分页 / 虚拟滚动两者都提供，工具条上可切：分页（默认 50 条 / 页，可选 50 / 100 / 200）+ 虚拟滚动（只挂可视区 ± 6 行）。任务树形态下虚拟滚动为「冻结表头 + 窗口化行」。已定
置顶 / 最近使用每行一个 ★ 置顶（写本地存储，不改任务字段），置顶区固定在列表上方；「最近使用」= 最近打开过的 5 条，同样固定在顶部，用「清空」移除。已定
⚠ 任务侧「标签」任务表 没有 tags 字段。本稿把任务上已有的 类型 / 优先级 / 状态 徽标当作「标签」并可点选筛选，不新增数据库字段。若你要自由标签（如「#内网」「#TTS」），需要一次 schema 迁移 16 + 编辑界面，请在这条上表态。请确认
⚠ 任务树 × 筛选命中子任务时保留父链作为「上下文行」（淡显、不计入条数），与现状一致；分页按 顶层根节点 计数，父任务与其子树不拆到两页（避免出现无父的孤儿行）。请确认
性能与验收口径（写进实现阶段的证据）：① 工具条「指标」记录 filter / sort / render 三段耗时；② 1200 与 3000 条各做一次“输入关键词 → 出结果”的实测，取 P50/P95；③ 修前 / 修后对照 = 本页「并排对比」形态（左侧下拉、右侧 Tab，同一份数据）。
实现时的落点（与项目规范一致）：src/client/taskFilterSort.ts 之外新增纯函数模块 src/client/listViewState.ts（Tab / 筛选 / 排序 / 分页的唯一权威源）与 src/client/components/ListToolbar.tsx、src/client/components/TabBar.tsx、src/client/components/PagedList.tsx，判定不进组件、组件不放业务判定。
