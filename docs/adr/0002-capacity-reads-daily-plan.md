# 容量以「今日计划」为准

**Status:** accepted（2026-09-30；同日补齐快照与计划项结束契约）

## 背景

旧容量只认今天到期、无截止但在推进、可选逾期：未来截止长任务不在候选，到了截止又把整条估时砸进一天。今日计划已有每日顺序，但原先没有投入分钟，也未参与容量。

## 决定

容量“已排”由当日计划派生；计划项有 minutes 快照（今天投多少分钟）和独立 effortDone（今天是否结束投入）。默认分钟在提案创建时取任务合法预计耗时/设置默认；显式编辑才变化。**不能以任务状态或今日投入结束自动改分钟快照。**

当日到期而未排入的不计已排，必须显示“未排入：N条 / X分钟（建议投入）”及一键排入。无计划时已排=0，不回退到到期任务求和。

## Considered Options

- **保持到期日驱动**：靠每天一条子任务拆长任务，任务树被切碎，补丁口径继续存在。
- **有计划用计划、无计划用到期日**：一个数字两个来源，重新引入双口径。
- **本轮不动**：不能解决长任务每日安排问题。

## Consequences

- minutes/effortDone存在daily_plans.items_json，不新增计划表列。旧JSON在进度迁移19中回填一次，坏JSON保留原串并诊断、不清空或伪装零容量。
- 到期日仍决定“什么时候该做”；提醒、逾期判定、日历到期展示不变。页面结构收敛仍属S14/批次2。
- 当日候选 = open ∩（当日到期 ∪ doing/blocked ∪ 当日已排 ∪ 开关启用的逾期待办）。在推进但未来截止的长任务必须出现。
- dailyCapacityIncludeOverdue存储键保留，文案改为“显示逾期待办候选”；只扩充候选，不改变已排；doing/blocked及显式已排不受开关隐藏。
- AI排序、手动添加、容量未排入区共用shared/dailyPlanPolicy纯函数与完整候选，不内联第二份过滤。
- AI稳定排序后最多列30条，提示词和UI明确总数/另有M条未列出，不声称全量排序。手动池/容量账本不截断。
- 已排=当日全部有效计划项minutes，包含已结束/任务done/cancelled/archived/缺失任务的投入历史；移除项才减去。
- 一键排入可改建议分钟，不改任务估时/截止；父子链冲突明确拒绝，不替换已有项。
- 独立投入结束与任务完成分流见[ADR0007](0007-daily-effort-is-not-task-completion.md)。

原现场的容量/排序不一致和slice(0,30)是本次修改的背景，不把旧行号作为长期判据。字段、兼容、错误、流程与算式的精确定义见[开发规格](../tasks/36c8e8ef-1104-4e68-b55f-a2a6cc533ab9-工作台插件优化/requirements.md) R-D/R-C，测试见同目录acceptance.md。
