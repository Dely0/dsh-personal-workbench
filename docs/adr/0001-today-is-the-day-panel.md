# 今日与日历收敛为同一个日期面板

**Status:** accepted（2026-09-30）

「今日」页与「日历选中某天」原本是**两份实现**（今日页 `src/client/index.tsx:3177-3273`，
日历当日面板 `:3316-3396`），重复了面板却**口径不一致**：今日树按「今天到期 / 逾期 / 进行中」，
日历计划树按「当日到期 ∪ 当日计划项」。

决定：**「某一天」只保留一个界面（日期面板）**，今日页降级为该面板的 **today 实例**
外加统计卡与容量条；两个视图的任务树口径统一，并逐条标注来源。

## 口径冻结（2026-10-01，用户拍板）

日期面板的任务树 = **当日到期 ∪ 当日计划项 ∪ 进行中**，每行标注命中的来源：

| 来源 | 判定 | 行标签 |
|---|---|---|
| 当日到期 | `effectiveDueAt` 落在该本地日 | 到期 |
| 当日计划项 | 该日 `daily_plans.items` 里的 `taskId`（**不看截止日**） | 计划 |
| 进行中 | `statusCode` 是 `doing` 或 `blocked` | 进行中 |

- 三者**并集去重**：一条任务可能同时命中多个来源 —— **全部标出**（按
  到期 → 计划 → 进行中 的固定顺序），不许只留一个，也不许用"主来源"覆盖其余。
- 只收 **open** 任务（`src/shared/taskProgress.ts#isOpenTask`）：`done` 归「已完成」页签、
  `cancelled` 一律不进树。
- 计划项指向的任务**已不存在**时不进树（树只渲染真实任务）；计划面板照旧保留该行并标注
  「任务不存在」（T2 已实现），两处不矛盾：一个是任务视图，一个是计划账本。
- 父/祖父仅作上下文时**灰化且不计入统计**（与「已完成」页签的 `doneContextIds` 同形状）。

**唯一实现**：这三个来源的判定必须收在 `src/shared/dailyPlanPolicy.ts` 的**同一个纯函数**里，
候选池 `planCandidates()`（ADR0002 用）与日期面板树**都从它派生** ——
不允许组件里再 filter 一遍（本项目最大的 bug 类别正是"同一语义两处算"）。

## Considered Options

- **A（采纳）今日 = 日历选中今天的同一份实现。** 一份实现、口径不可能再打架，
  且「已完成」页签（日历当日面板已有）自动获得。
- **B 保留两页，只抽共享组件**：改动小，但仍是两处装配 ——
  本项目历史上最大的 bug 类别正是「同一语义两处实现」（`panelState.ts` 那次事故即由此而来）。
- **C 删掉今日页，日历默认落在今天**：最彻底，但最高频入口从一次点击变两次。

## Consequences

- 容量条（**容量**）随之成为日期面板的一部分，而不再只属于「今日」。
- 原计划中的「客户端 `WorkbenchApp` 拆分」（`docs/design/2026-09-09-client-split-backlog.md`）
  **必须排在本决定落地之后**：页面结构未定就拆分，等于拆两遍。
- 「进行中但无截止」的任务原先只出现在今日树里，收敛后要在日期面板里有明确归属，
  否则这类任务会**静默消失**（这正是本项目最忌讳的丢件形态）—— 冻结口径下它由
  **进行中**这个来源承接，不再需要"暂列今天"的特例说明。
- **今日页的可见集合会变窄（刻意变更，必须在发布说明里写明）**：今日树原先列出**全部**未完成
  任务（`buildTaskTree(openTasks)`），收敛后只列三个来源命中的那些。截止在几天后、又没有
  排进今天计划、状态还是 `todo` 的任务，将不再出现在今日页 —— 去「任务」页或日历里看。
- ⚠️ **未决（留给用户拍板，实现时按冻结口径走）**：**逾期**任务
  （`effectiveDueAt < 今天` 且 open）不属于上面三个来源，于是只会因为"进行中"或"已排入计划"
  才出现。是否把「逾期」作为**第 4 个来源**（行标签「逾期」，或由设置开关控制）尚未定案；
  在定案前不要顺手加，但统计卡里的逾期计数保持可见（它是"有多少事过期了"的全局读数）。
- 受影响判据（改之前先读）：`test/capacityWiring.test.mjs`（候选函数调用点计数与容量接线）、
  `scripts/verify/suites/daily-effort.mjs`（三处 `clickByText('今日', '.wb-seg')` 的真实点击）。
