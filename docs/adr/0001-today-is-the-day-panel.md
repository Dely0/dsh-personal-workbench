# 今日与日历收敛为同一个日期面板

**Status:** accepted（2026-09-30）

「今日」页与「日历选中某天」原本是**两份实现**（今日页 `src/client/index.tsx:3177-3273`，
日历当日面板 `:3316-3396`），重复了面板却**口径不一致**：今日树按「今天到期 / 逾期 / 进行中」，
日历计划树按「当日到期 ∪ 当日计划项」。

决定：**「某一天」只保留一个界面（日期面板）**，今日页降级为该面板的 **today 实例**
外加统计卡与容量条；两个视图的任务树口径统一，并逐条标注来源。

## 口径冻结（2026-10-01，用户拍板）

日期面板的任务树 = **当日到期 ∪ 当日计划项 ∪ 进行中**，每行标注命中的来源：

| 来源 | 判定 | 行标签 |
|---|---|---|
| 当日到期 | `effectiveDueAt` 落在该本地日 | 到期 |
| 当日计划项 | 该日 `daily_plans.items` 里的 `taskId`（**不看截止日**） | 计划 |
| 进行中 | `statusCode` 是 `doing` 或 `blocked` | 进行中 |

- 三者**并集去重**：一条任务可能同时命中多个来源 —— **全部标出**（按
  到期 → 计划 → 进行中 的固定顺序），不许只留一个，也不许用"主来源"覆盖其余。
- 只收 **open** 任务（`src/shared/taskProgress.ts#isOpenTask`）：`done` 归「已完成」页签、
  `cancelled` 一律不进树。
- 计划项指向的任务**已不存在**时不进树（树只渲染真实任务）；计划面板照旧保留该行并标注
  「任务不存在」（T2 已实现），两处不矛盾：一个是任务视图，一个是计划账本。
- 父/祖父仅作上下文时**灰化且不计入统计**（与「已完成」页签的 `doneContextIds` 同形状）。

**唯一实现**：这三个来源的判定必须收在 `src/shared/dailyPlanPolicy.ts` 的**同一个纯函数**里，
候选池 `planCandidates()`（ADR0002 用）与日期面板树**都从它派生** ——
不允许组件里再 filter 一遍（本项目最大的 bug 类别正是"同一语义两处算"）。

## 口径补充：逾期 / 未排期两个页签（2026-10-02 用户拍板）

原因：冻结口径下，「今日」页只剩三个来源，于是**无截止、状态还是 `todo`/`backlog` 的任务在今日页没有任何入口**
（实测：库里 12 条 open 任务，命中三来源的 0 条）。用户报告"今日页空的、任务页却有一堆未完成"。
定案：**不动「计划」页签的口径**，另加两个页签把它们接住。

| 页签 | 判据（对某一天 D） | 只收 open |
|---|---|---|
| 计划 | 当日到期 ∪ 当日计划项 ∪ 进行中（**不变**，仍由 `dayPanelTreeSources` 唯一实现） | ✅ |
| **逾期** | `effectiveDueAt` 可解析且 **< D 的 00:00** | ✅ |
| **未排期** | **既不逾期、也不命中「计划」**（= 补集，不留死角） | ✅ |

三条硬规矩：

1. **「未排期」是补集**：`open − 计划 − 逾期`。三者合起来恰好是全部 open 任务，
   且「未排期」与另两者**互不相交** —— 一条任务若已排进今天/正在进行中，它就不是"未排期"。
2. **「逾期」允许与「计划」重叠**（**事实重叠**，刻意）：逾期是事实，不因它同时被排进今天而消失；
   一条"逾期 + 进行中"的任务会同时出现在「计划」（标签 进行中）和「逾期」里。
   所以**不要**把"三个页签计数之和 == open 总数"当作不变量（只有 计划 ∪ 逾期 ∪ 未排期 == open 成立）。
3. **`blocked` 留在「计划」（进行中）**，不进「未排期」；**「已取消」不加页签**（终态，回看走「任务」页的状态筛选与归档视图）；
   **重复任务的模板行**与**归档任务**照旧排除（与候选池同口径）。

其它已定口径：

- **过去日期不显示这两个页签**：真正的历史快照要回放 `task_events` 的状态历史，而库里只有"当前状态"——
  把今天的欠账画到 9/20 那一天就是编造。日历选中今天/未来时照常显示（未来日是"到那天为止"的投影）。
- **统计卡的「逾期」与页签同口径**（同一天界、同一个 `classifyTaskDay`）：原先统计卡用 `now`、
  树用当日 00:00，会出现"今天 09:00 截止的任务既算逾期又算今天到期"的双口径。
- **唯一实现**：页签成员判定收在 `src/shared/dailyPlanPolicy.ts#dayPanelTabMembers`（内部复用
  `dayPanelTreeSources` 与 `classifyTaskDay`），组件与装配层**不许再 filter 一遍**；
  由 `test/dayPanelTabs.test.mjs`（纯函数 + 组件渲染）与 `test/dayPanelWiring.test.mjs`（源码扫描）钉住。
- **行内「排入今日」**（2026-10-02 同日补）：只在**今天**这一实例 + **逾期 / 未排期**两个页签的行上出现，
  复用**唯一写入口** `addTaskToPlan`（`POST /plans/:date/items`，原子追加；组件只回调、不拼请求）。
  - 省略 `minutes` → 服务端按"任务预计耗时，否则设置里的默认投入"取快照，**回执里回显落库分钟**
    （只写"已排入"而不说投入多少，就是让用户去猜服务端替他决定了什么）；
  - 该行**已在今日计划中**（逾期 ∩ 计划的事实重叠）→ **不渲染按钮**（点了只会得到"已经在计划里"，是假入口）；
  - **未来日期不渲染**：现版本没有"未来排期"的入口（报告页签同样写着"AI 未来排期将在下版支持"），
    给未来日渲染一个写着"排入今日"的按钮、点了却排到今天，就是骗人。

**明确不做**：不把「逾期」加成"计划"树的第 4 个来源（那会让"计划"页签混进没排期的任务，
让人误以为已排入今日）；不改 `daily_plans` 的形状；不动容量算法（容量仍只算计划投入快照，ADR0002）；
本次**不做**未来日期的排期入口。

## Considered Options

- **A（采纳）今日 = 日历选中今天的同一份实现。** 一份实现、口径不可能再打架，
  且「已完成」页签（日历当日面板已有）自动获得。
- **B 保留两页，只抽共享组件**：改动小，但仍是两处装配 ——
  本项目历史上最大的 bug 类别正是「同一语义两处实现」（`panelState.ts` 那次事故即由此而来）。
- **C 删掉今日页，日历默认落在今天**：最彻底，但最高频入口从一次点击变两次。

## Consequences

- 容量条（**容量**）随之成为日期面板的一部分，而不再只属于「今日」。
- 原计划中的「客户端 `WorkbenchApp` 拆分」（`docs/design/2026-09-09-client-split-backlog.md`）
  **必须排在本决定落地之后**：页面结构未定就拆分，等于拆两遍。
- 「进行中但无截止」的任务原先只出现在今日树里，收敛后要在日期面板里有明确归属，
  否则这类任务会**静默消失**（这正是本项目最忌讳的丢件形态）—— 冻结口径下它由
  **进行中**这个来源承接，不再需要"暂列今天"的特例说明。
- **今日页的可见集合会变窄（刻意变更，必须在发布说明里写明）**：今日树原先列出**全部**未完成
  任务（`buildTaskTree(openTasks)`），收敛后只列三个来源命中的那些。截止在几天后、又没有
  排进今天计划、状态还是 `todo` 的任务，将不再出现在今日页 —— 去「任务」页或日历里看。
- ✅ **已定案（2026-10-02）：逾期不进"计划"树，改为独立页签** —— 见下面的「口径补充」。
  统计卡里的逾期计数保持可见（它是"有多少事过期了"的全局读数）。
- 受影响判据（改之前先读）：
  - `test/capacityWiring.test.mjs`（候选函数调用点计数与容量接线）；
  - `scripts/verify/suites/daily-effort.mjs`（三处 `clickByText('今日', '.wb-seg')` 的真实点击）；
  - `test/dayPanelTree.test.mjs`（计划树的三个来源，**口径未变**，改动后必须仍全绿）；
  - `test/dayPanelTabs.test.mjs`（2026-10-02 新增：三个页签的划分性质 + 组件真渲染的五页签/过去日期/空态）；
  - `test/dayPanelWiring.test.mjs`（源码扫描：判定只有一处、组件与装配层不许自己 parse 截止或比状态）；
  - `test/panelCss.test.mjs`（页签间距 + **五个页签必须允许换行**，否则窄面板上最后一个页签静默消失）；
  - `scripts/verify/suites/day-panel.mjs`（B 层：五页签、两个新页签点得开且行数==计数、过去日期藏页签且兜底到计划）。
