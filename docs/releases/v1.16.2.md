## 3. 逐条变更

### 3.1 「逾期」/「未排期」两个页签（ADR0001 口径补充）

- 判据（对某一天 D，全部只收 open）：

  | 页签 | 判据 |
  |---|---|
  | 计划（**未改动**） | 当日到期 ∪ 当日计划项 ∪ 进行中 |
  | **逾期** | `effectiveDueAt` 可解析且 < D 的 00:00（**允许**与「计划」重叠：逾期是事实） |
  | **未排期** | `open − 计划 − 逾期`（补集；与另两者**不相交**） |

- **判定只有一处实现**：`src/shared/dailyPlanPolicy.ts#dayPanelTabMembers`（内部复用既有的
  `dayPanelTreeSources` 与 `classifyTaskDay`）；组件与装配层**不再 filter 一遍**，由源码扫描钉住。
- `blocked` 留在「计划」（进行中）；**不加「已取消」页签**（终态，回看走「任务」页的状态筛选）；
  重复任务的模板行与归档任务照旧排除。
- **过去日期不显示这两个页签**：真正的历史快照要回放 `task_events` 的状态历史，而库里只有"当前状态" ——
  把今天的欠账画到 9/20 那一天就是编造。日历选中今天/未来时照常显示。
- 过去日期上页签**兜底到「计划」**（`resolveDayPanelTab` 一处实现：装配层复位 state 与组件渲染共用它），
  否则会出现"面板显示计划、列表却是空的"**假空**。

### 3.2 统计卡「逾期」口径统一

- 原先统计卡用 `now` 判逾期、日期面板树用当日 00:00 判到期 —— "今天 09:00 截止、现在 20:00"的任务
  会**同时**计进「逾期」和「今天到期」。现在两者都走同一个 `classifyTaskDay`（当日 00:00）。
- 直接后果：统计卡的「逾期」数字可能比之前**小**（当天已过点但未到次日的任务现在算"今天到期"）。

### 3.3 行内「排入今日」

- 只在**今天**这一实例 + **逾期 / 未排期**两个页签的行上出现；复用**唯一写入口** `addTaskToPlan`
  （`POST /plans/:date/items`，服务端事务内原子追加；组件只回调、不拼请求）。
- 省略 `minutes` → 服务端按"任务预计耗时，否则设置里的默认投入"取快照，**回执里回显落库分钟**
  （只写"已排入"而不说投入多少，等于让用户去猜服务端替他决定了什么）。
- 该行**已在今日计划中**（逾期 ∩ 计划的事实重叠行）→ 不渲染按钮（点了只会得到"已经在计划里"，是假入口）；
  正在排入 → 禁用 + 文案「排入中…」；未来日期 → 不渲染（现版本没有未来排期入口，渲染一个写着"排入今日"却排到今天的按钮就是骗人）。

### 3.4 测试基建（夹带项）

- `tsconfig.build.json` 增加 `src/client/components/DayPanel.tsx`：客户端 `.tsx` 默认只被 tsdown 打进
  `lib/client.js`，**不会**产出可被 `node --test` import 的单独文件；列进 tsc 根后才会发射
  （传递依赖 `PlanPanel.tsx` 一并发射）。**包内因此多两个文件**，对使用者无影响。
- **容量变异探针重锚（`scripts/repro/probe-capacity-mutations.mjs`）**：原 M1–M9/M15–M18 锚的是
  `src/client/capacity.ts` 里的**旧客户端容量实现**，而容量计算在 ADR0002 就迁进了
  `src/shared/dailyPlanPolicy.ts` —— 那 14 条锚点整段消失，探针报"找不到替换片段"，被发布门禁判为
  **阻塞项**（门禁立场：探针失效 ≠ 欠账，必须先修）。现按当前口径重锚为
  **12 条共享模块变异（S1–S12）+ 接线/面板 8 条（I1–I5 / P1–P3）**，并为原先"装回缺陷仍全绿"的 6 处
  **补了判据**：`test/capacityWiring.test.mjs` 4 条源码扫描（编辑耗时的保存 payload / 编辑框初值 /
  就地校验 / 乐观更新）+ 1 条"面板不许自己 reduce 求和"；`test/capacityPanel.test.mjs` 1 条勾选态判据
  （逾期开关必须是真控件）。结果 **20/20 全红**，`KNOWN_PROBE_DEBT` 里的容量条目**已删除**。
- 口径落在 [`.dsh/skills/dsh-plugin-change/SKILL.md`](../../../.dsh/skills/dsh-plugin-change/SKILL.md)（项目级技能）。

## 4. 破坏性变更

- **「今日」/「日历」的日期面板从 3 个页签变成 5 个**（计划 / 逾期 / 未排期 / 已完成 / 报告）；
  习惯"只有计划"的用户会看到两个新页签（这是本版的目的）。页签允许换行（窄面板上被挤掉的页签会**静默消失**，已有静态判据）。
- **统计卡「逾期」数字口径变化**（见 3.2）——不是 bug，是刻意统一。
- 包内新增 `lib/client/components/DayPanel.js` / `PlanPanel.js`（见 3.4）。
- **无 schema 变化**（仍 `SCHEMA_VERSION = 19`），升级不需要迁移动作。

### 门禁状态（发版前必须先转绿）

**已转绿。** 过程如实记录：

- 首次跑 `release-preflight` 时停在 **1 条阻塞项**：`probe-capacity-mutations` 探针失效
 （14 条锚点指向 ADR0002 之前就已迁走的旧客户端实现）——这是 **2026-10-01 登记的既有欠账，不是本版引入的**。
- 门禁的立场是刻意的：`scripts/lib/releasePreflight.mjs#judgeProbes` 明确写着「**"探针失效"与"基线没过"
  不算欠账，直接失败**」，所以名单里那条记录不能解锁 —— **先修探针，再发布**。
- 处置（见 3.4）：按当前口径重锚 + 补 6 条判据 → 探针 **20/20 全红**；
  `KNOWN_PROBE_DEBT` 里的容量条目已删除（双向断言要求"还清必须销账"）。
  维护记录：[`docs/issues/2026-10-01-mutation-probe-maintenance.md`](../../issues/2026-10-01-mutation-probe-maintenance.md) §A2。
