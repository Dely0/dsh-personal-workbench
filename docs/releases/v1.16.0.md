## 2. 主线一：任务进度（显式、可报、不可被 AI 代完成）

新增纯模块与 UI：`src/shared/taskProgress.ts`、`src/db/repo/progress.ts`、
`src/client/taskProgressView.ts`、`src/client/components/TaskProgress.tsx`。

口径（已固化为 ADR）：

- **进度是显式字段**（ADR 0004），不是从子任务或日投入派生的派生值；
- **AI 不能靠进度完成任务**（ADR 0003）：`100%` 必须走"完成任务"这个显式动作与确认；
- **日投入 ≠ 任务完成**（ADR 0007）。

界面：列表行内紧凑进度条 + 详情页完整卡（五档预设 / 输入框 / 子任务旁证）。

## 3. 主线二：专家人格角色库（三级来源 + 15 篇内置）

### 三级来源（前者优先）

| 级别 | 位置 | 写权限 |
|---|---|---|
| 用户库 | `~/.dsh/workbench/personas/` | 用户自己放 |
| 外部目录 | 设置项 `personaExternalDir`（默认空） | **只读**，工作台从不写 |
| 内置 | 包内 `assets/personas/` | 只读 |

形态与公司内部角色库**完全对齐**（`# 名称` + `> 元信息块` + 正文），所以公司现有的 9 篇
**零改动可读**。可选 frontmatter 只支持顶层标量 `name/description/group/mode/emoji`。

### 内置角色从 6 篇扩到 15 篇，并分成两个来源区

```
assets/personas/
  generic/   6 篇  本项目自写的通用工作方式型角色
  domain/    9 篇  领域/岗位型角色（.NET ×3、天线/电磁/微波 VNA/仪表回路/不确定度/计量溯源）
```

分区不是装饰，而是**判据的一部分**：

- `generic/` 有一条**黑名单扫描**（不许出现领域岗位名或上游素材关键词）——
  用来证明"内置的通用角色没有被公司素材污染"；
- `domain/` 有一条**署名判据**（每篇必须逐条登记在 `THIRD_PARTY_NOTICES.md`，
  两份 MIT 全文必须在 `files` 里）——少一条就红灯。

> 这两条判据取代了原先"内置角色恰为六篇且不含领域关键词"那一条：
> 它**不能原样留着**（与事实打架）、**也不能直接删**（会丢掉"通用区不许被污染"这条真实约束）。

### 会话绑定与工具

- 首次 prompt 前把「本次角色」绑定到该会话（`ai_session_registry` 的 `persona` scope）；
- 工具按**真实** `exec.sessionId` 加载，正文**不进提示词**（提示词只加一行）；
- 文件 revision 变化明确拒绝旧绑定；换角色须新会话；
- 资源只限同名附件目录的文本相对路径，有大小/类型/realpath 边界，禁止 link/junction 越界与执行脚本。

## 4. 主线三：研发版本验收链 + 客户端 P0

### 验收链（`scripts/dev-verify.mjs`）

13 阶段：`preflight → version-before → build → install → profile-diff → dump-config →
version-after → restart → health → token → suites → evidence → cleanup-browser`，
退出码 `0/1/2/3` 语义化。

- `scripts/verify/`：CDP 驱动（真实鼠标事件）、证据收集、白名单 `suites.json` 与 8 个套件；
- `scripts/build-info.mjs`：构建时写入 `buildId`，让"页面跑的到底是哪份构建"可核对
  （`health` 与浏览器根属性两侧一致才算通过）；
- token 只从环境变量读，日志里注册脱敏，**绝不写入证据**。

### 客户端 P0：面板里的链接不再导航宿主文档

症状：桌面端点面板里的链接会**导航宿主文档**，桌面端不可恢复、Web 端页面被顶走。
根因：全仓唯一的链接渲染点直接输出裸 `<a href>`（没有 `target`/`onClick`）。
修复：http(s) 走 `target=_blank rel=noopener noreferrer` + `preventDefault` + `openExternalLink`；
非 http(s) 不渲染 `<a>`。

## 6. 破坏性变更 / 需要注意的变化

1. **数据库 schema 18 → 19**（单向前进）。降级插件将读不了更新的库；请升级而不是降级库。
2. **内置角色 id 的路径形态变了**：`engineering/实现者` → `generic/engineering/实现者`。
   角色 id 是收藏 / 停用 / 会话绑定记录里的**持久键**，所以旧记录指向的角色会显示为
   "已不在角色库里"。重新选一次即可；`domain/` 下的新角色不受影响。
3. **设置页新增独立「角色库」页签**：收藏 / 停用从角色选择器与「通用」页搬到这里；
   这一页的收藏/停用是**点一下立即生效**（不等「保存设置」），外部目录字段仍走保存。
4. **详情页「归档」移到右上角**（与「编辑」并列）；AI 动作按钮文案精简
   （"父任务 / 需可执行 / 续作"等信息进 `title`）。
